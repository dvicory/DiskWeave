# Reviewer observations

POST-HOC ORACLE. DO NOT INCLUDE IN AGENT EVALUATION INPUT.

The Milestone 8 semantic-reconciliation process exposed several consequential mistakes or review questions. A future run can be scored on whether it independently identifies and handles them correctly.

## Canonical semantic ownership audit

The run must preserve the distinction between:

- rejected/generation-mismatched recovery commit; and
- lost/corrupt/indeterminate commit observation.

An indeterminate observation must not make the prior snapshot authoritative.

Semantic dependency review invalidation must follow the complete dependency closure rather than stopping after one hop.

`requires` and `refines` must remain semantically distinct:

- `requires` consumes an independently owned fact;
- `refines` specializes or realizes the same underlying policy;
- composition alone is not refinement.

Consequential known semantic relationships must be authoring obligations rather than merely optional annotations.

Linux verification evidence must not itself create or broaden the canonical supported Linux profile.

## Ownership implementation

Local semantic fingerprints must exclude relationship markers.

Effective semantic/review fingerprints must include outgoing relationships and target effective fingerprints so semantic changes propagate through the dependency closure.

Deterministic tooling validates authored semantic relationships but does not infer undeclared semantic edges from arbitrary prose.

Retirement of the Linux correction-program requirement must remap evidence only where each retained artifact actually proves the target requirement.

## Metadata authority

Caller-constructible certificate classifications must not authorize certificate-gated metadata recovery.

Certificate-gated cases remain visible but non-authorizing until a real validator-issued non-forgeable receipt exists.

Operator confirmation must not substitute for that missing receipt.

## Canonical request boundary

Stable SlotId/topology identity must determine member selection; positional/vector order must not become alternate authority.

The exact canonical BlockRequest must survive admitted terminal failure as well as successful completion.

Lower-level backend OperationId may remain when it has an independent backend-operation purpose; name overlap alone is insufficient reason for deletion.

## Final verification

Planning artifacts and milestones must remain non-authoritative and mechanically excluded from current semantic context.

Final retained Linux evidence must correspond to the final no-active-change source state.

A compressed archive SHA-256 affected by gzip metadata is an exact archive-byte identity, not a deterministic content identity.
